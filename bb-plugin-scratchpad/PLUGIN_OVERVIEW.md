Scratchpad adds a floating whiteboard you can open anywhere in bb with ⌘⇧J.
Use it to sketch with a pen, lines, arrows, rectangles, ellipses, diamonds,
triangles, and freeform polygons, and to add text and sticky notes. You can
keep several boards; each one autosaves.

To reference a board, type `@` in any thread's composer and pick it. The
agent receives the board's notes, text, and connections, plus a rendered
image.
