Launcher replaces bb's ⌘K thread search with a Raycast-style window. It shows
threads that need attention, running and pinned threads, and recent threads
and projects ranked by how often and how recently you open them, plus a preview
of each thread's latest messages.

Type to search threads, projects, branches, message text, commands, settings,
and plugins, plus results from plugins that add their own, such as Spotify
songs and playlists, or type a prompt to start a thread in any project. The
best match comes first as the top hit, and an exact match always wins. With
the telecom-ref plugin running, 3GPP Diameter commands, AVPs, interfaces, and
network functions show up too, so typing SAR puts Server-Assignment first.

You rarely need the arrow keys: ⌘1 to ⌘9 run the first nine results, Tab opens
the selected project, plugin, page, or telecom entry, and Tab on an empty
search jumps back to the thread you were in before. Press ⌘K on a result for
its actions: pin, rename, send a message, mark unread, stop, archive, and
everything else in bb's thread menu, including other plugins' actions. Toggle
app settings, switch themes, change the default agent, and enable, disable, or
configure plugins without leaving the keyboard.
